# Active work

One row per in-flight spec. Rows are added when a spec is created (`draft`),
flipped to `active` on approval, and removed when the plan closes (spec →
`archive/`, plan → `agents/archive/`). See `td-project-workflow.md`.
`research-platform-roadmap-spec.md` holds the long-horizon view for the
**research-platform** axis (PyTorch/JAX table stakes);
`datascience-platform-roadmap-spec.md` does the same for the
**data-science** axis (sklearn/statsmodels/NetworkX/Spark/matplotlib roles)
and records the stdlib / `dev.cajeta.ml` / new-library grouping.

**Open questions closed 2026-08-01.** All 16 data-science-track specs had their
open-question sections resolved in one pass — 15 load-bearing decisions taken
directly, the remainder accepted on their stated recommendation, and 11 stale
items closed where a later decision had already answered them. What remains
open is listed per spec and is action rather than judgement (an audit, a
version pin, a packaging choice). Two consequences are structural and are
tracked below: `cajeta-text-shaping` is a **new spec not yet written**, and
`cajeta-rag` moves **last** in the build order.
