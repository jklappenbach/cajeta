One row per in-flight spec. Rows are added when a spec is created (`draft`),
flipped to `active` on approval, and removed when the plan closes (spec →
`archive/`, plan → `agents/archive/`). See `td-project-workflow.md`.
`research-platform-roadmap-spec.md` holds the long-horizon view for the
**research-platform** axis (PyTorch/JAX table stakes);
`datascience-platform-roadmap-spec.md` does the same for the
**data-science** axis (sklearn/statsmodels/NetworkX/Spark/matplotlib roles)
and records the stdlib / `dev.cajeta.ml` / new-library grouping.
