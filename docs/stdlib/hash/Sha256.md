# Sha256

`cajeta.hash.Sha256` — SHA-256 (FIPS 180-4), a 256-bit cryptographic digest:
collision- and preimage-resistant, the SHA-2 family member the rest of the
stack relies on for integrity. TLS certificate validation, `cvm`'s
release-checksum verification, and `HttpClient.downloadTo`'s streaming
download integrity are all built on it — the `update`/`digest` streaming
shape exists so an incremental digest over arriving chunks equals the
one-shot digest of the whole input.

```cajeta
Sha256 sum = heap Sha256();
int8[] chunk = heap int8[64];
sum.update(chunk, 64);
String hex #= sum.hex();   // finalize → 64-char lowercase hex
```

## Methods

| Signature | |
|---|---|
| **One-shot statics** | |
| `static #int8[] hash(int8[] data, int64 len)` ⚑ | 32-byte digest of `data[0..len)` |
| `static #String hashHex(int8[] data, int64 len)` ⚑ | Lowercase 64-char hex digest of `data[0..len)` |
| `static #int8[] hashString(String s)` | 32-byte digest of a `String`'s UTF-8 bytes |
| `static #String hashStringHex(String s)` | Lowercase hex digest of a `String`'s UTF-8 bytes |
| **Streaming** | |
| `Sha256()` ⚑ | Construct a fresh streaming hasher |
| `void update(int8[] data, int64 len)` | Append `data[0..len)` to the streaming digest |
| `#int8[] digest()` | Finalize and return the 32-byte digest (terminal — state is consumed; `reset()` to reuse) |
| `#String hex()` | Finalize and return the lowercase 64-char hex digest (terminal) |
| `void reset()` | Re-initialize the working state |
| `int64 finish()` | `Hasher` projection: first 8 digest bytes as a little-endian `int64` — hash-table use only, never for integrity; integrity callers use `digest()` / `hex()` |
| **`Hasher` typed writes** | |
| `void writeBoolean(boolean v)` | Append `v` as one byte: `1` for true, `0` for false |
| `void writeInt8(int8 v)` | Append the raw byte of `v` |
| `void writeInt16(int16 v)` | Append the 2 raw bytes of `v` |
| `void writeInt32(int32 v)` | Append the 4 raw bytes of `v` |
| `void writeInt64(int64 v)` | Append the 8 raw bytes of `v` |
| `void writeUInt8(uint8 v)` | Append the raw byte of `v` |
| `void writeUInt16(uint16 v)` | Append the 2 raw bytes of `v` |
| `void writeUInt32(uint32 v)` | Append the 4 raw bytes of `v` |
| `void writeUInt64(uint64 v)` | Append the 8 raw bytes of `v` |
| `void writeFloat32(float32 v)` | Append the 4 raw bytes of `v` |
| `void writeFloat64(float64 v)` | Append the 8 raw bytes of `v` |
| `void writeBytes(int8[] data)` | Append every byte of `data` |
| `void writeBytesRange(int8[] data, int64 offset, int64 length)` | Append `length` bytes of `data` (v1: `offset` is ignored) |
| `void writeString(String s)` | Append a `String`'s UTF-8 bytes |
| `void writeObject(Object obj)` | Mix in `obj.hash()` as 8 bytes |

⚑ = `@EntryPoint`
