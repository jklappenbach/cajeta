# Standard library reference

One document per main component class, one directory per package
(`cajeta.io.net.http` → `io/net/http/`). Classes and their entry points are
keyed by the `@EntryPoint` doc tag in the stdlib sources.

*(Being authored — the package index lands with the first reference pass.
Until then, `cajeta doc runtime/src/cajeta -o <dir>` generates the API site,
including the entry-points index.)*
