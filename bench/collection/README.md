# cajeta.collection

The collections, each against the standard container of five languages and, where one exists, the fastest known library in that language.

| Page | |
|---|---|
| [ArrayList](ArrayList.md) | The growable, index-addressable sequence backed by a doubling T[] |
| [LinkedList](LinkedList.md) | The doubly-linked list |
| [HashMap](HashMap.md) | The SwissTable-backed map over a dense entry array |
| [HashSet](HashSet.md) | The hash-based set of unique values |
| [Heap](Heap.md) | The array-backed binary heap and priority queue |
| [RedBlackTree](RedBlackTree.md) | The ordered map, a CLRS red-black tree |
| [BPlusTree](BPlusTree.md) | The in-memory ordered map with B+ tree leaves in a linked chain, built for range scans |
| [Cache](Cache.md) | The bounded cache with LRU eviction and optional TTL |
| [ImmutableList](ImmutableList.md) | The immutable array-backed list |
| [ImmutableMap](ImmutableMap.md) | The frozen hash-indexed map snapshot |
| [ImmutableSet](ImmutableSet.md) | The frozen hash-indexed set |
| [Collectors](Collectors.md) | The standard Collector factories for stream terminal operations |
| [Sort](Sort.md) | General-purpose host sorting and the shared comparison protocol |
| [LtmBPlusTree](ltm/LtmBPlusTree.md) | The disk-backed, larger-than-memory ordered map |
